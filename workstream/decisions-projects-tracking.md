# Decisions: projects-tracking

Decision log for `docs/requirements/prd-projects-tracking.md`. IDs are unique within this file; cite them elsewhere as `projects-tracking#D-NN`. Superseded rows are kept; the superseding row names the row it replaces. Evidence rows cite the riel experiment report `workstream/experiment-projects-campaign-ui.md` (llipe/riel, 2026-10-20), which ran these conventions against one live wave with every write approved by the owner.
